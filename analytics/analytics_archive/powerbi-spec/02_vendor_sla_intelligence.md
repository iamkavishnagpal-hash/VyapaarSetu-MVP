# Power BI Dashboard Spec 2: Vendor SLA Intelligence

## Visual Specifications
- **Visual 1 (Scatter Plot)**: Vendor On-Time Rate (%) vs. Defect Rate (%). Bubble size = Total PO Volume.
- **Visual 2 (Matrix Grid)**: Vendor Tier Scorecard. Columns: `Vendor ID`, `Name`, `City`, `Composite Score`, `Escrow Verified`, `Tier Badge`.
- **Visual 3 (Card)**: Preferred Vendor Count (Score ≥ 90.0) vs. High Risk Count (Score < 75.0).
