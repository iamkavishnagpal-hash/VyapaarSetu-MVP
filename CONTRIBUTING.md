# Contributing to VyapaarSetu

Thank you for your interest in contributing to the **VyapaarSetu** platform!

## Code of Conduct
We are committed to providing an open, welcoming, and inclusive environment for all contributors.

## Pull Request Guidelines
1. Fork the repository and create a feature branch (`git checkout -b feature/amazing-feature`).
2. Ensure any new Python automation scripts compile cleanly with `python -m py_compile automation/*.py`.
3. Verify that all 17 CSV datasets maintain key integrity (`vendor_id`, `store_id`, `product_id`, `order_id`).
4. Submit a clear Pull Request with reference to relevant evidence artifacts.
